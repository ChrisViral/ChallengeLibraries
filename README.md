# Challenge Libraries
These are my personal libraries which have been written for my [Advent of Code](https://github.com/ChrisViral/AdventOfCode) solutions,
and now being put to use on other code challenges.

## Challenge.CLI
Commandline/Entry point interfacing. Responsible for taking CLI arguments, instantiating the proper solver,
fetching the problem input, and then feeding it to the solvers.

## Challenge.Collections
Various collection utilities and searching utilities, as well as 2D grids.

## Challenge.Generator
Source generation for solvers parsing and automatic setup.
More details about usage can be found in it's decdiceted [README](./Challenge.Generator/README.md).

## Challenge.Maths
Mathematics, numerical, and vector utilities.

## Challenge.Solvers
Base setup code for problem solvers.

## Challenge.Utils
Various utility methods and extensions.
